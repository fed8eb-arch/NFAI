# Training — Исследователь рынка (Market & Competitor Researcher)

Mission role: module 01, and the competitor / demand input to modules 02–03.

## Business process

1. **Define the market actually served** (geography, buyer, job to be done). For a US pilot, use US sources first. Do not import Yandex Direct / Avito / VK plans as if they were the US channel mix (those appear in Petrochenkov and Gorny decks as RU practice).
2. **Map competitors from official pages** (name, URL, claim, date fetched, HTTP status). Reliability rule: no scout report without source, date, and reliability.
3. **Collect the questions buyers ask** (forums, official FAQs, sales notes) and hand them to the Prompt Engineer. This is the input to Share of Voice, not a keyword dump.
4. **Map citation surfaces** that actually appear in the target search/AI answers (Shestakov p. 21: in one cited study, Reddit, YouTube, Amazon, NYT took many page-1 slots; RU analogues differ). Note where the brand is absent.
5. **Use paid tools only if approved** (Ahrefs, Semrush, Surfer, Rush Analytics). Until then, public pages and official docs. If a paid tool is approved later, export raw evidence; do not paste vendor “AI scores” as NFAI’s own proof.
6. Deliver a brief that module 05 can use: what would count as a qualified lead in this market, and what price or margin figures are **unknown** (do not invent CAC).

## Services you master

Public official sites and documents; later, if approved, Ahrefs / Semrush / Surfer as research tools. Maps/listings relevant to the geography (GBP for US; Yandex/2GIS only if the market is theirs). Citation surfaces as sources, not as products.

## Measurable outcomes

| Outcome | How it is measured | Pass |
|---|---|---|
| Competitor table | ≥ 3 competitors with official URL, fetch date, and what the page actually claimed | Every row has a URL and date; no unsourced “leaders” |
| Buyer question list | Count handed to module 02 | ≥ 20, each with a source |
| Citation-surface map | List of off-site places that already rank or get cited for the pilot queries | Sourced; gaps marked as gaps |
| Unknowns log | Missing TAM, spend, conversion baselines | Explicit “unknown — need Founder / data”, not a made-up number |
| Brief | One dated memo used by modules 02–05 | Used as input (link from the next task), not a dead file |

## Acceptance test

- [ ] Every market claim has a URL or a labelled assumption.  
- [ ] No RU channel is recommended for a US-only property without a reason.  
- [ ] Question list is usable unbranded in AI engines.  
- [ ] Paid tools, if any, have a Founder yes ID.  
- [ ] No OSINT report without source, date, and reliability.
