## Форма Netlify → наш обработчик

Пилот WireReady уже на Netlify (`wireready-pilot.netlify.app`). Готового коннектора «Netlify Forms → выбранная CRM» в просмотренных официальных документах нет; пишем свой приёмник.

Официальные пути (оба принимают только **проверенные**, не спам, отправки):

1. **Исходящий webhook.** В UI: Forms → Submission notifications; уведомления можно слать на email, webhooks или Slack, для одной формы или для всех. Через API: `POST https://api.netlify.com/api/v1/hooks` с `type: "url"`, `event: "submission_created"`, `data.url`. Ответ `410 Gone` от конечной точки удаляет hook. ([уведомления форм](https://docs.netlify.com/manage/forms/notifications); [Netlify API, раздел Hooks](https://docs.netlify.com/api-and-cli-guides/api-guides/get-started-with-api/))
2. **Netlify Function.** Обработчик события `formSubmitted` (новый синтаксис) или устаревшее имя файла `submission-created` — срабатывает, когда отправка формы проверена. ([trigger functions on events](https://docs.netlify.com/build/functions/trigger-on-events))

Тариф Netlify (важно для нулевого бюджета). На **credit-based** планах Forms бесплатны и без лимита. Functions тарифицируются как compute: 1 GB-Hour = 10 кредитов; у Free — 300 кредитов в месяц с жёстким потолком. Какой именно план (credit-based или legacy) у аккаунта пилота — **не проверено**. На legacy Forms и Functions лимитируются отдельно. ([Forms usage](https://docs.netlify.com/manage/forms/usage-and-billing); [Functions usage](https://docs.netlify.com/build/functions/usage-and-billing/); [credit-based plans](https://docs.netlify.com/manage/accounts-and-billing/billing/billing-for-credit-based-plans/credit-based-pricing-plans))

**Ограничение архитектуры.** Роутер LLM агентства слушает `127.0.0.1:4000` на боксе и с облачной Netlify Function недоступен. Обработчик должен либо работать на машине с доступом к роутеру (публичный webhook на бокс / воркер на боксе забирает заявки), либо иначе доставлять событие на бокс. Это не требует платного API, но требует согласованной схемы приёмника. Менять сайт без «да» Основателя нельзя.

## Наша интеграция (модуль 04 AI Conversion Engine)

Собственную CRM не собираем. Собираем клей и процесс квалификации (стратегия BUY + INTEGRATE + BUILD; NFAI не реселлит тариф CRM).

Поток MVP:

1. Заявка с формы сайта (Netlify Forms) приходит в наш обработчик (webhook или функция + доставка на бокс). Позже в тот же конвейер — email и чат на сайте (каналы, подтверждённые Директором).
2. Пишем журнал события (без секретов и без выкладки PII в публичный репозиторий). Дедупликация по email.
3. AI-скоринг: только согласованные поля, через локальный роутер `127.0.0.1:4000`, сначала бесплатные модели (`free-chat`). **Клиентские PII в Gemini free-tier не отправляем.** Если модель вернула пустой ответ или ошибку — статус «нужна ручная проверка», лид не теряется (известный сбой `free-chat` при малом `max_tokens` описан в `INFRA.md`).
4. В CRM: найти контакт по email; создать или обновить контакт и связанную сделку (воронка). Источник / UTM / «how did you hear about us?» — сохраняем в карточке (**допущение** по составу полей, плюс рекомендация из обучения, Shestakov p. 50 — сверить с расшифровкой).
5. Человек может поправить скор. Цель первого ответа лиду меньше чем за 5 минут — **допущение / предложение**; по файлу обучения это целевой SLA, фактическое время надо измерять, а не считать принятым.
6. Ошибки: очередь и повторы для доставки webhook/API (учёт 429/5xx и лимитов выбранной CRM); алерт, если карточка не создана. Наблюдаемость: модель, задержка, стоимость вызова (без ключей в логах репозитория).
7. Соответствие законам США: CAN-SPAM (отписка в каждом письме); TCPA (SMS и звонки только с явным согласием — в MVP не входят); CCPA (экспорт и удаление по запросу; у выбранной CRM должен быть путь экспорта без тикета вендора).
8. Смена вендора: схема лида и журнал остаются у NFAI; CRM можно заменить, не продавая клиенту «белый» тариф вендора.

Критерии приёмки MVP (**допущение**, перенесённые из v0.1 и подлежащие сверке): тестовый лид из формы → карточка без дубля → скор с объяснением → первый ответ (цель < 5 мин, факт записывается) → запись на встречу → событие в отчёте. Всё — логами на тестовых данных, на согласованном (staging / разрешённом) пути. Регистрацию CRM и правки боевого сайта не начинаем без «да» Основателя.

Не входит в MVP: голосовые AI-звонки, SMS-рассылки до проверки TCPA, собственный email-провайдер, сборка полноценной CRM.

## Рекомендация

**По умолчанию для пилота США при бюджете 0: HubSpot Free.** Из трёх вариантов это единственная CRM, у которой одновременно есть постоянный бесплатный тариф и REST API на этом тарифе (документально: 2 пользователя, 1 000 контактов, 250 000 вызовов API в сутки / 100 запросов за 10 с для частных приложений, английский интерфейс, дата-центры в США). Лимиты для первого пилота (мало пользователей, объём контактов < 1 000) по документации подходят. Формы оставляем на Netlify, поэтому брендинг форм HubSpot для приёма заявок не обязателен.

Kommo после 14 дней требует оплату (минимум 6 месяцев, Base от $25 за пользователя в месяц) — при бюджете 0 не подходит как постоянная база. Bitrix24 Free даёт CRM и неограниченных пользователей, но **без REST API и webhooks**, поэтому наш конвейер «форма → скоринг → CRM» на постоянном бесплатном плане туда не встраивается (только на 15-дневном trial или на платном Vibe+).

Окончательный выбор аккаунта — после «да» Основателя. Рекомендация не является регистрацией.
