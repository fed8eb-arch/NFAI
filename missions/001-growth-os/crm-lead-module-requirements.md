# Product C — AI Conversion Engine: CRM/лид-модуль, требования v0.1
Дата: 2026-11-23 · Автор: Разработчик интеграций · Статус: черновик
Примечание: в репозитории NFAI нет описания Product C, а видео конференции не просмотрено. Это допущения инженера, их надо сверить с выводами по Rush Conf.

## Цель
Принять каждый входящий лид (американский рынок), квалифицировать его за минуты, довести до записи на звонок или до покупки и показать, откуда пришли деньги (атрибуция).

## Функциональные требования
1. **Приём лидов:** формы сайта (webhook), чат-виджет, email, импорт CSV; позже Meta/Google Lead Ads. Один API `POST /leads`, без дублей (email/телефон).
2. **Карточка лида:** контакт, компания, источник, UTM-метки, история касаний, согласия (opt-in), статус, владелец.
3. **AI-квалификация:** LLM через роутер `127.0.0.1:4000` (бесплатные модели первыми) извлекает бюджет, потребность, сроки, ЛПР; выдаёт скор 0–100 с объяснением; человек может поправить.
4. **AI-диалог:** первый ответ лиду меньше чем за 5 минут (email/чат), уточняющие вопросы, отработка возражений по базе знаний, запись в календарь. Передача человеку по триггеру.
5. **Воронка:** настраиваемые этапы (New → Qualified → Booked → Won/Lost), правила автоматического перехода, задачи и напоминания.
6. **Follow-up:** последовательности касаний; остановка при ответе или отписке.
7. **Аналитика:** конверсия по этапам и источникам, скорость первого ответа, стоимость лида (если есть данные о расходах), выручка по каналам.
8. **Интеграции:** двусторонняя синхронизация с HubSpot/Pipedrive (первый релиз: одна из них), календарь, Stripe (оплаты), Slack-уведомления.

## Нефункциональные требования
- **Соответствие законам США:** CAN-SPAM (отписка в каждом письме), TCPA (SMS и звонки только с явным согласием), CCPA (экспорт и удаление данных по запросу).
- **Безопасность:** ключи только в env/хранилище секретов; PII не отправляется в модели без согласованного DPA (Gemini free-tier — без PII); журнал доступа.
- **Надёжность:** очередь с повторами для webhook; лиды не теряются при падении LLM (fallback: скор = «нужна ручная проверка»).
- **Наблюдаемость:** лог каждого вызова модели (модель, задержка, стоимость); алерт, если первый ответ не ушёл за 5 минут.
- **Мультиарендность:** данные клиентов агентства изолированы.

## Не входит в MVP
Звонки голосом через AI, SMS-рассылки (до проверки TCPA), собственный email-провайдер.

## Критерии приёмки MVP
Тестовый лид из формы → карточка без дубля → скор с объяснением → ответ меньше чем за 5 минут → запись на встречу → событие в отчёте. Всё подтверждено логами на тестовых данных.
