## Brain Bridge protocol (how Buddy and ChatGPT Codex exchange tasks)

Source: PR #1 body, `bridge/README.md`, `bridge/knowledge/PROTOCOL.md`, `bridge/knowledge/CHATGPT_WORK_EVENT_TASK.md` on branch `nfai-brain-bridge`.

1. VIP-Custom is a **private asynchronous mailbox**, not GPT inference and not direct access to ChatGPT hidden context. Default branch `main` must stay unchanged. **Do not merge PR #1.**
2. A local agent with a question writes an immutable file `bridge/questions/<UTC timestamp>-<id>.md` on `nfai-brain-bridge`. A brief PR comment tagged `NFAI-QUESTION <question-id>` may later serve as a trigger — only after an event task exists.
3. ChatGPT / Codex, when independently active (scheduled hourly check or a future event task), should read the question plus `bridge/knowledge/` and scoring policy, then write `bridge/answers/<same id>.md` on the same branch.
4. **There is no working event wake today.** The native ChatGPT Work event task is a setup specification only (`NOT YET CREATED`; event-source discovery previously returned HTTP 404). A PR comment alone does not wake GPT.
5. The mailbox is not a live endpoint and does not guarantee instant replies. No secrets, raw chats, keys, or unredacted logs may be posted.
6. Merit / score registry lives under `bridge/score/` on this private branch, not in the public NFAI repo.
