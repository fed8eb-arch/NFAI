# Общий граф памяти NFAI

[graph.json](graph.json) связывает все ролевые профили, Основателя и Бадди с линиями подчинения и наставничества. В рабочей части графа есть фазы проекта, приёмка Claude Code, ручные шаги и решения о бюджете и регистрациях. У каждого узла и каждой связи указан источник.

При передаче задачи открой свою роль и нужную задачу, затем прочитай указанные источники. Актуальный статус бери из [status.md](../../status.md), решения из [journal.md](../../journal.md), ручные шаги из [inbox/needs.md](../../inbox/needs.md). Граф служит индексом к этим файлам.

Из корня репозитория с Python 3.10+:

```bash
python3 _core/memory/query.py list
python3 _core/memory/query.py show buddy
python3 _core/memory/query.py show codex-joker
python3 _core/memory/query.py show document-workflow
python3 _core/memory/query.py check
```

При изменении роли, задачи, решения или блокера сначала обнови источник. Если изменилась связь в графе, обнови её в том же коммите. Сохраняй существующие ID, указывай путь к источнику и запускай `check` перед отправкой. Публичная ветка содержит только допустимые к публикации сведения. Ключи, пароли, персональные данные и закрытые материалы в граф не добавляй.

Передача Бадди по документам находится в [inbox/needs.md](../../inbox/needs.md#бадди--claude-code-для-документов-nfai). Ручные строки inbox остаются в исходнике, а граф ведёт к ним через узел `manual-signup`.

В Claude Code проектный хук `PostToolUse` проверяет граф после `Edit` или `Write` файла `graph.json` и возвращает агенту результат в контекст. Скрипт не меняет файлы. Запуск Claude Code с `--safe-mode` отключает пользовательские хуки, поэтому для таких запусков выполняй `query.py check` вручную.

В `.mcp.json` зарегистрирован локальный сервер `nfai-memory`. Для запуска нужен `uv`. Инструмент `memory_list` перечисляет узлы, а `memory_show` показывает связи и источники. Правки вносятся в исходные файлы и граф. Claude Code запросит одобрение проектного MCP при первом использовании.
