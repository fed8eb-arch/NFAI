# Daily Checks Registry
Version 1.1 | 2026-11-27 | Founder-approved; runtime acceptance pending | Owner: Orchestrator
AGENTS.md governs permissions and HOLD/STOP. Daily = incremental changes over 24h and a small rotating sample, not full model-driven audits. Check only active authorized scope; no product-project inspection during NFAI infrastructure audit. No invented automated schedule. One line per check: OK / issue / not applicable / blocked, evidence, owner and next step. Fixes follow normal approval. Prompt Engineer always first.

| # | Check | Owner | Scope |
|---|---|---|---|
| 1 | Prompt consistency, version, actual identity, role boundaries, brief and changed-prompt regressions | Prompt Engineer + Tester | changed + five rotating unchanged |
| 2 | Clearance log, accepted intelligence evidence | Internal Security | changed entries |
| 3 | Secret/access least privilege, offboarding | Internal Security / DevOps | changes + one account |
| 4 | Public exposure | Counterintelligence | new authorized public materials |
| 5 | Training preparation | Professor | three roles' verified work, one training file, five links; no exercises/exams under HOLD |
| 6 | Root cause of errors and preventive fix | Orchestrator / Professor | new errors |
| 7 | Existing backup and lightweight restore | DevOps / Delivery | last backup + one sample checksum; isolated restore, no overwrite |
| 8 | Uptime, incident status, delivery | Delivery | active authorized systems |
| 9 | Costs, quota and unused integrations | Cost Controller | actual change, no new costs |
| 10 | Receivables/forecast | Finance | only live authorized scope; otherwise N/A |
| 11 | Campaign control | Marketing | only approved live campaign; CPL >50% over target after 3 full days or test budget: flag pause under existing authority |
| 12 | Client/product SLA/backlog | Client Relations / Product | approved active scope; first reply SLA 4 business hours |
| 13 | Strategic decisions | Buddy / Business Angel / AI Mentor | new decisions only |

Daily summaries before Director report; daily short Mon–Sat, detailed Sunday. Deep restore monthly (measure time, isolate, check hashes); incident drill quarterly only when authorized; full training link/file review monthly, no formal exercises while HOLD. Spaced review intervals 1 week/1 month/1 quarter after admission. Existing quarterly/financial/client reports keep cadence where authorized. No new backup automation or deletion based on this document alone.
