# Fable access (Claude Fable 5.x) — где доступна, в каком режиме, порядок переходов
> **Решение Основателя t304u (17.11.2026, записал Оркестратор):** ВНУТРЕННЕЕ — МОЖНО, ДО КЛИЕНТОВ. Пока нет клиентов, Arena, Design Arena, Poe и другие звенья разрешены для внутренней работы, включая финальную проверку на Fable. С появлением клиентов покупаем подписки и заново проверяем ToS. Условия сервисов (вручную, один аккаунт, страна по Anthropic) по-прежнему действуют. Регистрации не одобрены.

- Задача: R2 (Оркестратор). Дата проверки: 2026-11-17, America/New_York. Только чтение публичных страниц; ничего не регистрировали.
- Назначение (из router-design.md): Fable используется только на финальной вычитке/улучшении готового результата, не для создания с нуля.
- **[API]** = строка для проверки Разработчиком интеграций. Все найденные API-варианты Fable **платные** (бесплатного API-доступа к Fable не найдено) → только с одобрения основателя.
- Hop order = переход к следующему сервису, когда дневной лимит исчерпан. Один аккаунт на сервис; новые аккаунты/браузеры для обхода лимитов НЕ используем (это нарушает ToS, напр. OpenRouter, и нашу политику). Совет из материалов «5 аккаунтов в разных браузерах» не применяем.
- «нужен вход» = список моделей/лимиты видны только после входа; мы не входили.
- **Решение Директора 17.11.2026 13:32 ET:** (1) Arena — только вручную, только внутренние задачи, без данных клиентов, автоматизация запрещена. (2) Финальная Fable-проверка клиентских работ — только через сервисы цепочки, чьи условия разрешают коммерческое использование ответов (колонка «Годится для клиентских работ»). (3) Платный Fable API не одобрен — все П-строки «не одобрено». 
- Данные клиентов в Arena.ai и Design Arena не отправлять: их условия разрешают публиковать/коммерциализировать переписки.
- Arena.ai ToU (https://help.arena.ai/articles/5629909088-terms-of-use, Last Updated 2026-02-23, прочитаны 17.11.2026): не более одного аккаунта; запрещён программный/автоматизированный доступ и скрейпинг (агенты не должны управлять Arena через браузер-автоматизацию); запрещено коммерчески эксплуатировать Output — использование ответов Fable из Arena в клиентских материалах требует решения Оркестратора/Основателя. Arena API Developer Preview (platform.arena.ai) изучен 17.11.2026: только по приглашению («Invite only… No invite? Join the waitlist»), нужен способ оплаты («You must provide Company with a valid payment method»), прямые модели — только за платные или промо-средства («Direct models need paid or promotional (all models) funds»), список моделей — «нужен вход» (GET https://api.arena.ai/v1/models → 401). AUP: запрещено «commercially exploit or make available… Output… to any third party, or… for the benefit of third parties, except as expressly permitted». ### Вывод (отдельно от фактов)
- **Design Arena — не годится для клиентских работ**: прямой запрет коммерческого использования и использования в интересах третьих лиц; весь Output принадлежит Arcada Labs; ввод передаётся провайдерам для обучения и может публиковаться.
- **uncensored.com — нет данных**: условия молчат о правах на ответ, о странах и о бизнес-использовании; лимит Fable не подтверждён. До письменного подтверждения от сервиса для клиентских работ не использовать.
- **Arena.ai — нет** (Решение Директора 17.11.2026 13:32 ET: только вручную, только внутренние задачи).
- **Poe (веб) — единственное звено, которое по условиям допускает клиентскую работу**, при всех условиях сразу:
  1. только официальный бот @anthropic Claude-Fable-5.x (полный щит — нет обучения);
  2. только вручную, один аккаунт, без скриптов;
