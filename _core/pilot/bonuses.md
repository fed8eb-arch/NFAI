Правила: только публичные страницы, без регистраций и входов. Траты = 0. Что не сказано на официальной странице — «нет данных»; недоказанный факт — UNVERIFIED. Сырые копии страниц: `/workspace/pilot/research_raw/bonuses/`. Надёжность цифр: средняя (официальные страницы, тарифы меняются).

Контекст: частное лицо, **без компании и без сайта**. Россия упоминается только если это написано на странице (в просмотренных страницах явных ограничений именно для РФ почти нет).

## Классы (как применялись)

Справка менторов: **A** — без карты и без трат; **B** — нужна карта / юрлицо / инвестор (решение Основателя); **C** — сейчас закрыто или недоступно.

Для этой таблицы классы уточнены под бриф «частное лицо без компании и сайта» (если в справке B и C смешаны, здесь они разделены):

- **A** — без карты, без трат, доступно частному лицу.
- **B** — нужна карта «на файле», сам бесплатный объём доступен частному лицу (привязка карты — только с решения Основателя; холд верификации на страницах описан как не списание, но это всё равно карта).
- **C** — нужно юрлицо, статус студента, сайт, заявка в программу, либо для частного лица без трат недоступно (в т.ч. регистрация сразу списывает деньги).

Строки с двумя стадиями помечены **A/B**. Обходы телефона, KYC и карты не предлагаются.

- Для агентства при правиле «ноль трат, без карты» сейчас реально брать класс **A**: Cloudflare (Workers/Pages/R2/Workers AI), GitHub Free и Copilot Free, Supabase, Vercel Hobby (только некоммерческое/личное), Netlify, Render (с оговорками sleep/Postgres 30 дней), Hugging Face Hub/ограниченные Spaces, Gemini API Free, Groq Free, OpenRouter `:free`, Neon, Firebase Spark, MongoDB Atlas Free, плюс коротко AWS Free plan (если карта не запросят) и урезанный Deno Free.
