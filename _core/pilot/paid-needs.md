### Китайские модели — кратко (факты)
- Бесплатный API без карты: Z.ai GLM-4.7-Flash / 4.5-Flash / 4.6V-Flash («Free»; API-данные не хранятся по DPA; РФ не в списке запретов ToS). Alibaba Qwen — ~1M токенов/модель на 90 дней, только Singapore, «Free Quota Only» включать заранее; данные не для обучения.
- Нет бесплатного API: DeepSeek (предоплата; данные в КНР; на обучение — «to a minimal extent», отказ — выключить «Improve the model for everyone»), Kimi API (пополнение от $1), MiniMax (пополнение).
- Веб-версия Kimi и Dola — только некоммерческое использование: для клиентских работ нельзя.
- Baidu Qianfan, Volcengine, Tencent Hunyuan — китайские облака с квотами 1M токенов, но вход по телефону/реальному имени КНР (Tencent — подтверждено, остальные UNVERIFIED); для нас не путь.
- На OpenRouter :free китайские только `baidu/ernie-5.5-flash-preview:free` и `inclusionai/ling-3.2-flash:free`; Qwen, DeepSeek, GLM и Kimi среди бесплатных нет (openrouter.ai/api/v1/models, 2026-11-17).
- Открытые веса (DeepSeek MIT, GLM Apache-2.0, Qwen-Image/Wan2.2 Apache-2.0) законны, но без GPU на общем компьютере не запускаются.

### Вердикт по гипотезе (вывод Исследователя, не факт)
- ВЕРНА для текста, кода, анализа, транскрибации, поиска, хостинга, мониторинга, CRM и дизайна макетов. Это 9 из 15 кандидатов, их отклоняем.
- НЕ ВЕРНА или верна частично:
  - Видео и поток изображений: открытым китайским моделям нужен GPU, а бесплатные веб-лимиты разовые.
  - Голос: ElevenLabs запрещён для РФ, качество бесплатного русского голоса UNVERIFIED.
  - SEO-данные конкурентов: у моделей нет данных о ссылках и трафике.
  - Право РФ: нужны первоисточники.
  - Реклама: бюджет нельзя заменить моделью.
- Юридические и дата-ограничения:
  - Kimi (веб) и Dola запрещают коммерческое использование.
  - DeepSeek хранит данные в КНР.
  - Бесплатный Gemini недоступен из РФ и обучается на данных.
  - Qwen автоматически списывает деньги без «Free Quota Only».
- Платных подписок «купить сейчас» нет. «Не сейчас — по заказу»: Midjourney, Semrush/Ahrefs, видео, правовая база, hh.ru.
- Перепроверка (effort high): Vercel Hobby подтверждён как некоммерческий — хостинг клиентов только Cloudflare Pages Free или за счёт клиента; Brave Search API требует карту — исключён.
- Ни одна альтернатива не проверена тестом; тесты делает Разработчик интеграций.
