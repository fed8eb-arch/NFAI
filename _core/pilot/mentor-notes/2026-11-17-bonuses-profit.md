## 1. Бизнес-ангел
- **Бесплатный ресурс = сэкономленный доллар.** У стартапа без выручки каждый бесплатный кредит уменьшает будущие расходы, то есть увеличивает будущую прибыль (Баффетт: не терять деньги; Тиньков: юнит-экономика; Бакалчук: рост на своих средствах).
- **Ошибка дня.** «$100» в OpenRouter оказалось лимитом ключа, а не подарком (Credits $0.00). Но решение «отозвать ключ» было принято без справки Совета. Правило: ничего бесплатное не отклонять и не отзывать без справки (необратимое решение — особенно).
- **Границы.** Только легально и без трат: без карты, без «накрутки» нескольких аккаунтов ради лимитов (это нарушение правил сервисов и риск бана всех аккаунтов агентства). Одна регистрация на сервис, один набор данных.
- **Решения о карте, деньгах, юрлице** (многие стартап-программы требуют компанию и платёжный метод) — только Основатель; фиксируем как «нужно решение Основателя», не как «невозможно».
- **Вердикт:** охота за бонусами — обязательный шаг каждой регистрации; потолок риска — $0 трат и нуль обходов проверок.

## 2. ИИ-ментор (технологический, отдельный блок)
- **Мнение:** бесплатные уровни API (Gemini, OpenRouter :free, Cloudflare и др.) достаточны для прототипов и тестов агентов; для продакшена они ненадёжны (лимиты не гарантированы, данные могут идти на улучшение продукта).
- **Фактическая оговорка:** лимиты бесплатных уровней меняются; брать только со страницы провайдера в день проверки, в реестр писать дату проверки.
- **Риски:** (1) бесплатный уровень Gemini API: содержимое может использоваться для улучшения продуктов — не слать клиентские и личные данные; (2) кредиты часто привязаны к первому провайдеру/модели и истекают; (3) зависимость от провайдера (lock-in) — писать абстракцию над провайдером.
- **Оценка стоимости:** нет данных о реальном расходе агентства в токенах; нужен замер Cost Controller по неделе. До замера экономию в долларах не заявлять.
- **Уверенность:** средняя (цифры берутся с динамичных страниц). Расхождений с Ангелом нет.

## 4. Как системно искать и забирать бонусы (процесс)
Порядок для каждого нового сервиса (до или сразу после регистрации):
1. Открыть на сайте сервиса страницы **Pricing, Billing/Credits, Promotions, Startups/Programs, Docs → Limits**. Записать, что нашёл: «бесплатный уровень», «кредиты при регистрации», «пробный период», «программа для стартапов».
2. Поиск: `<сервис> free credits 2026`, `<сервис> startup program`, `<сервис> promo code`; приоритет — страницы самого сервиса, затем независимые обзоры. Обзоры — подсказка, не доказательство: сумму подтверждает страница провайдера.
3. Проверить условия: нужна ли карта, юрлицо, сайт компании, инвестор/партнёр; срок действия; что покрывают (какие модели/сервисы); возврат/штрафы при исчерпании.
4. Классифицировать: **A** — берём сразу (без карты, без трат); **B** — нужна карта/юрлицо/инвестор → «нужно решение Основателя», не делаем сами; **C** — недоступно (закрытый набор, регион).
5. Забрать только A. Реферальные подарки: только официальная реферальная программа сервиса и только свой реальный аккаунт; чужих людей и «ферму» аккаунтов не использовать.
6. Сделать скриншот страницы кредитов (без ключей и паролей) и записать в реестр.
7. Поставить напоминание за 14 дней до срока истечения (Оркестратор ведёт).

## 5. Чек-лист на один сервис (копировать в бриф)
- [ ] Просмотрены Pricing / Credits / Promotions / Startups / Limits (ссылки записаны).
- [ ] Найден ли бонус: что, сколько, срок, условия (карта? юрлицо? инвестор?).
- [ ] Класс A/B/C назначен; для B — вопрос Основателю подготовлен (с ценой и риском).
- [ ] Бонус A забран; баланс/лимит виден на странице аккаунта (скриншот без секретов).
- [ ] Запись в `accounts.md`, колонка **bonus**: `что | сумма | срок | доказательство (файл/скриншот, дата проверки)`; если ничего нет — «нет (проверено <дата>)»; если не проверено — «UNVERIFIED».
- [ ] Ничего не отозвано и не отклонено без справки Совета.

## 6. Формат записи в accounts.md, колонка `bonus`
`<что> | <сумма, валюта> | <срок до даты> | <доказательство: путь к скриншоту или URL страницы, дата проверки ET>`
Примеры формата (не факты о наших аккаунтах): `бесплатный API-уровень | лимиты по странице | без срока | screenshots/gemini-limits-2026-11-17.png`; `нет (проверено 17.11.2026, Credits $0.00)`.
Текущее: OpenRouter — «нет: Credits $0.00; $100 — лимит ключа». Остальные сервисы — «UNVERIFIED» до проверки.

## 8. Решение Директора (проект)
1. Бонусный шаг становится обязательным в чек-листе регистрации (колонка `bonus` в accounts.md заполняется всегда).
2. Сейчас забираем только класс A: Gemini free (после регистрации Google), OpenRouter :free (уже есть), Cloudflare Workers AI (после проверки).
3. Классы B (Google for Startups, AWS Activate, Microsoft for Startups, NVIDIA Inception) — Основателю одним вопросом: «есть ли у NFAI юрлицо и сайт компании, и разрешаешь ли ты привязку карты без траты (кредиты вместо оплаты)?» Без его ответа не регистрируем.

5. Любой отказ от бесплатного ресурса или отзыв ключа/аккаунта — только после справки Совета.
6. Урок «Прибыль и бонусы» — `director.md` v1.4, раздел 12.
