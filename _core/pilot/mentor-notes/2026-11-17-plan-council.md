# Совет по основному плану

Версия 1.0 · 17.11.2026 ET · Джокер

- **Бизнес-ангел.** Сначала максимум Value, при равенстве — Ease. Считать бонус полученным по данным аккаунта. При карте или оплате зафиксировать стоп и перейти к следующей позиции.
- **ИИ-ментор.** Разделять веб, API и доступ через LiteLLM. Проверять бесплатный API одним коротким тестом. Ручной вход передавать владельцу; ключи хранить только в разрешённом каталоге.
- **Профессор.** Сверить все 72 номера с источниками и отделить сохранённые результаты от свежих наблюдений. Для каждого стопа указать доказательство и шаг возобновления. После приёмки фазы 1 перейти к инфраструктуре.

Заключения смоделированы Джокером по трём ролям. Независимые ответы менторов недоступны в этой сессии.
