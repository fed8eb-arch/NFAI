# Каталог бесплатных ИИ-сервисов из материалов основателя (задача R1)

- **Дата проверки:** 2026-11-17 (America/New_York, ET). Все строки проверены 17.11.2026, если не указано иное.
- **Исполнитель:** Исследователь рынка. **Режим:** только чтение публичных страниц (WebFetch / WebSearch / curl). Никаких регистраций, входов, форм, контактов.
- **Метод:** список сервисов взят из материалов (Navigator 2026, 51 ссылка: `/workspace/yadisk/docs/navigator_links.txt`; Arena.ai гайды; `ССЫЛКА НА 2-Й СЕРВИС…`, `Ссылки на другие ИИ сервисы без цензуры`) + добавлен Design Arena по указанию основателя (только официальный домен). Утверждения навигатора источником НЕ считаются. Каждый факт сверен с официальной страницей сервиса (docs / pricing / ToS / help). Если официальная страница недоступна или отдаёт только JS-оболочку, использован сторонний источник, надёжность понижена до low. Неизвестно = «нет данных».
- **Надёжность:** high = цифры прочитаны на официальной docs/pricing/ToS странице; med = официальная страница частично (или факт найден в официальном help/блоге через поиск); low = только сторонний источник.
- **Шкалы:** Value 1–5 (бесплатный объём + качество моделей); Ease 1–5 (5 = только email … 1 = карта+KYC/платный план); Risk 1–5 (1 низкий … 5 высокий: карта, жёсткие ToS, бан, РФ заблокирована, приватность).
- **Важно для РФ:** ни один из сервисов не проверялся из российской сети. «Доступность из РФ» = только то, что написано в официальных списках регионов / ToS. Обход региональных ограничений через VPN нарушает ToS тех сервисов, где РФ не в списке (Google Gemini API, OpenAI) и запрещён нашей политикой.

- **Fable (Claude Fable 5.x):** отдельный файл `/workspace/pilot/fable-access.md`.

Легенда флагов: 💳 = бесплатных API-токенов нет / нужна карта или предоплата / платный план; ⚠️ToS = ограничение ToS (мультиаккаунты, автоматизация, коммерция, регион).
