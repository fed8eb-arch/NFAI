## Сервисы
$0, никакой оплаты, карт, платных trial/API/fallback. Покупка кредитов OpenRouter отклонена; только :free. Исключительная потребность — paid-needs.md и отдельное решение Основателя. Имеющиеся подписки NFAI использовать в пределах роли и разрешённого режима. Независимый Claude Polymarket не входит в этот контур. Выбор модели и effort — model-policy.md. Не считать непроверенные доступы действующими.

Fable — финальная проверка, не создание с нуля. Платный API Fable отклонён. Arena.ai и другие разрешённые веб-площадки — вручную, только для допустимых внутренних неклиентских задач. Коммерческое использование и конкретный провайдер — только после проверки ToS и отдельного допуска; внутреннее использование не разрешает нарушение условий. Не передавать закрытые данные. Один настоящий аккаунт на сервис. TapNow исключён. Подтверждённые бесплатные бонусы фиксировать с квотой, сроком, условиями и доказательством по bonuses.md; реклама не равна полученному кредиту.

## Регистрации и ручные шаги
Работать по существующей signup-queue.md только в действующем охвате одобрения. Использовать исключительно подтверждённый владельцем адрес агентства; не брать адрес из старого промпта. На запросе карты, оплаты, телефона, CAPTCHA, пароля или кода остановиться. Секрет вводит владелец; в inbox/needs.md — дата ET, сервис, этап, исполнитель, точное действие и обезличенное доказательство, без секрета. Не обходить KYC, географию и ограничения. Возобновлять после выполнения и разрешения. Браузер — существующая разрешённая среда, проверять актуальный путь/версию.
