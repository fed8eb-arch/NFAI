# Проверка локального маршрута Claude Code · 19 ноября

После очистки рабочей среды CLI и локальные сервисы отсутствовали. Восстановлены Claude Code 2.1.327, OmniRoute 3.8.53 и локальная Qwen3-4B. Контрольная сумма модели совпала с записью проекта. При двух запусках llama-server завершился SIGKILL; при другом запуске провайдер OmniRoute был автоматически отключён и шлюз вернул 401.

Для проверки провайдер снова включён, контекст во временной копии лаунчера уменьшен до 4096. Шлюз вернул HTTP 200 и контрольный ответ 43; CLI вернул 42. На вопрос, упоминает ли предоставленный краткий пересказ ролика требование AAC, CLI ответил NO, код завершения 0, 284 входных и 2 выходных токена. Проверка относится к переданному тексту, просмотр видео моделью не выполнялся.

Изменения временного лаунчера не внесены в проект. После проверки сервисы остановлены. Надёжный повторный запуск, полноразмерная обработка и качество ответов на других заданиях остаются открытыми.
