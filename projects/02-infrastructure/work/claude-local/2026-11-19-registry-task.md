# Проверка Claude Code на реестре видео

19 ноября. Локальный Qwen3-4B через OmniRoute и Claude Code обработал существующий реестр 18 роликов. Шлюз ответил HTTP 200, контрольный ответ 43. CLI выполнил Read и Write без ошибок, код завершения 0, сообщил 3320 входных, 196 выходных и 4280 кэшированных входных токенов. Новых платных расходов не было.

Запрошено выделить три незавершённые задачи из документа. Модель указала полноту дневной ленты, проверку лицензии конкретного SupoClip и автоматическую транскрипцию с поиском фрагментов. Два первых пункта отражают текст реестра. Третий требует уточнения: локальная транскрипция уже реализована и проверена на английской контрольной записи, а автоматический подбор фрагментов и проверка русской речи остаются открытыми. Следовательно, результат соответствует переданному документу, но для актуального состояния требуется сверка с более поздними изменениями проекта.

Первый запуск получил HTTP 200, затем завершился из-за отсутствия extract.py в восстановленной временной папке. Файл восстановлен из main, после чего задача выполнена. Сервисы остановлены после запуска. Задание является чтением и записью вывода по документу. Модель не меняла код и не просматривала видео.
