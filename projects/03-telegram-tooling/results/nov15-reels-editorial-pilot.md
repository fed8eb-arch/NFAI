## Assignment for the Content Manager

Given an audience, service, week and verified project result, deliver a seven-day draft calendar with an angle and evidence or production action per day. Pick one slot and write an original script with hook, demonstration, payoff and viewer action. Use the structural pattern only. Tie each performance claim to a reproducible observation. Mark unpublished drafts and hand them to the Head of Marketing.

## Внутренний пилот · 16–22 ноября 2026

Бриф: заказчик презентаций хочет проверить бриф перед передачей файла. Цель недели — показать границы автоматической проверки PPTX. Материал — наши собственные тестовые презентации. Весь календарь является черновиком.

| День | Работа редакции |
|---|---|
| Пн 16 | Черновик Reel «В брифе два слайда. Сколько в файле?» — показать собственный тест с одним слайдом. |
| Вт 17 | Подготовить карточку с полями брифа для следующего ролика: аудитория, цель, число слайдов, цвета. |
| Ср 18 | Черновик Reel «Можно ли исправить заголовок после сдачи?» — показать нативный текст в тестовом PPTX. |
| Чт 19 | Записать демонстрацию повторного запуска на исправленном файле. |
| Пт 20 | Черновик Reel «Проверка пройдена. Что смотреть глазами?» — показать переносы и цвет в собственном примере, проверить в редакторе перед съёмкой. |
| Сб 21 | Собрать три черновика и сверить озвученные числа с протоколом проверки. |
| Вс 22 | Передать главе маркетинга календарь и материалы; для публикации действуют полномочия из профиля контент-менеджера. |

**Оригинальный сценарий первого Reel, 15 секунд.** 0–3 с: крупно показать бриф «Два слайда». Голос: «Вам прислали готовый файл. Сколько слайдов в нём на самом деле?» 3–8 с: показать запуск проверки и строку `Slides: 1/2`. 8–12 с: открыть второй вариант и рядом показать результат `Slides: 2/2`. 12–15 с: «Перед сдачей сравните файл с числом из своего брифа». Для захвата экрана использовать собственные данные.

**Приёмка фактов.** Исполнитель Codex повторно запустил [проверку PPTX](24-presentation-acceptance.md) с `--slides 2` на двух файлах. Для однослайдового файла получены 1/2 и код 1, для двухслайдового — 2/2 и код 0. Оценка дизайна, съёмка, публикация и замер охвата остаются отдельными шагами. Календарь и сценарий доступны в Claude Code и Codex как текстовое поручение; исполнение здесь проверено в Codex.
