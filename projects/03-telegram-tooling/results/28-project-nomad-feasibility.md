# Офлайн-база Project NOMAD

Источник ролика: [GrLM96WPw0w, 00:07–00:39](https://www.youtube.com/watch?v=GrLM96WPw0w). При открытии текста YouTube название распознано приблизительно. [Crosstalk Solutions Project NOMAD](https://github.com/Crosstalk-Solutions/project-nomad) соответствует описанию, но адрес проекта в кадрах или аудио пока не подтверждён.

README разработчика описывает локальную библиотеку Kiwix, ассистента с документами и семантическим поиском через Qdrant, локальные модели Ollama либо совместимый API, заметки и другие приложения. Это потенциальное дополнение к памяти NFAI, совместимость с существующим графом не проверена.

Проверка текущего окружения: Debian 13, пользователь uid 1000, свободно около 14 ГБ на /workspace, команды docker и podman отсутствуют, sudo отсутствует. Документация разработчика предлагает установку с правами root и Docker, для базовой системы указывает 5 ГБ, для включения AI ориентир — около 25 ГБ. Debian 13 не указан в основной таблице протестированных систем. Работа NOMAD и интеграция с NFAI не проверены: сервер не установлен и не запускался.

NOMAD не содержит встроенной аутентификации согласно README, поэтому доступ к рабочим данным требует отдельной изоляции и проверки. В случае появления пригодной среды — развернуть изолированную копию без секретов, подтвердить запуск, загрузку тестового документа, поиск и закрытие доступа с внешней сети. Учитывать время и доступный объём для модели и данных.
