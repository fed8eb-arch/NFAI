18.11.2026 ET · [Видео](https://www.youtube.com/watch?v=rQGobkHftpM) · [Lowfat](https://github.com/zdk/lowfat) · [Документация Claude Code](https://code.claude.com/docs/en/costs#offload-processing-to-hooks-and-skills)

|---|---|
| 00:00–00:13 | Вывод команд занимает контекст. Anthropic документирует предварительную обработку вывода через хуки. |
| 00:13–00:24 | Lowfat даёт хуки для Bash и Read. Размер эффекта зависит от команды и степени сжатия. Почти 92% в ролике — заявление об отдельном замере. Расход токенов на NFAI пока неизвестен. |

Проверил на десяти коммитах NFAI, заканчивающихся на `6813f62`. Вывод `git log -10 --oneline` занял 568 байт вместо 1807 у `git log -10`, то есть на 68,6% меньше. Проверка `git diff --quiet` на совпадающих деревьях, изменении и ошибочной ссылке вернула соответственно 0, 1 и 128. Это измерение объёма stdout и проверка кодов Git.

Применение для агентов NFAI. Для обзора истории используй `git log -10 --oneline`, для просмотра перечня изменений — `git diff --stat`. Для приёмки конкретной правки открой полный diff целевых файлов. При проверке наличия изменений код 1 означает изменения, ошибки Git требуют отдельной обработки.

Решение: использовать проверенные команды Git. Lowfat оставить для отдельного теста на сохранение ошибок и значимых строк. В этом прогоне Lowfat не запускался и хуки Lowfat не включались.
