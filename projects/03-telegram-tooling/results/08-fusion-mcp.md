# Claude и Autodesk Fusion

19.09.2026 · [Видео](https://www.youtube.com/watch?v=kTBf_8743aA) · [Документация Autodesk](https://help.autodesk.com/view/ADSKMCP/ENU/?guid=ADSKMCP_FusionDesktopMcp_autodesk_fusion_mcp_server_html) · [Коннектор Claude](https://claude.com/marketplace/connectors/autodesk-fusion)

На 00:25–00:52 ролик показывает подключение к Fusion. Autodesk подтверждает локальный MCP для живой настольной сессии Fusion. Это сценарий CAD и отдельная конфигурация рабочей станции. Из ролика нельзя проверить экономию, качество конструкции или пригодность детали к производству.

**Решение NFAI.** Отложить настройку до задачи с CAD и подходящего рабочего места. Для приёмки интеграции использовать простую учебную модель с проверяемыми размерами. Текущий пилот веб-дизайна и граф памяти от Fusion не зависят. Реальный запуск Fusion в этом прогоне не выполнялся.
