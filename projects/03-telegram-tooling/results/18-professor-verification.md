# Учебные проверки Профессора

2–6 ноября · [Harness², 00:14–00:33](https://www.youtube.com/watch?v=DoVJqkzL3VA) · [Код Google](https://github.com/google-research/harness2) · [TimesFM, 00:14–00:30](https://www.youtube.com/watch?v=YmIFVWlz0aY) · [TimesFM](https://github.com/google-research/timesfm) · [Code Mode, 00:37–01:05](https://www.youtube.com/watch?v=6hN5uiIqi40) · [Cloudflare](https://blog.cloudflare.com/code-mode-mcp/)

| Практика | Результат локальной проверки |
|---|---|
| Сравнивать изменения инструкций на одних и тех же задачах и заранее заданных критериях | На 4 синтетических случаях оценка правила выросла с 3/4 до 4/4 после добавления требования воспроизводимого теста. Модель не вызывалась. |
| Для прогноза сначала фиксировать сезонный и простой эталоны, затем оценивать по будущим наблюдениям | По 16 шагам синтетического ряда средняя абсолютная ошибка была 4,5 для последнего значения и 0 для сезонного эталона. TimesFM не запускался. |
| Возвращать из разрешённого инструмента только поля, нужные задаче | Из 32 вымышленных записей получены 8 требуемых ID, компактный JSON сократился с 8 015 до 22 байт. Токены и сетевые вызовы не измерялись. |

Процедура для Профессора и тестировщика. Запишите входы, ожидаемый результат, версию источника и процедуру повторения. Утверждение ролика и результат собственного теста храните раздельно. Harness² проверялся по документации, без облачного запуска. Лицензия весов TimesFM зависит от версии и назначения. Code Mode не настраивался на учётных данных агентства. Новая идея дополняет [Lowfat](04-lowfat.md): выбирать поля ответа в источнике информации, прежде чем передать их агенту.
