# Память Claude Code и заметки Obsidian

18.09.2026 · [Видео](https://www.youtube.com/watch?v=QICAidO6bOc) · [Документация Claude Code](https://code.claude.com/docs/en/memory) · [Хранилища Obsidian](https://obsidian.md/help/Files%2Band%2Bfolders/Manage%2Bvaults)

| Таймкод | Проверка |
|---|---|
| 00:00–00:12 | Obsidian хранит заметки в папке файловой системы. Claude Code получает долгосрочный контекст через проектные инструкции и локальную auto memory. Одного нового файла заметок недостаточно, чтобы Claude автоматически прочитал его. |
| 00:12–00:23 | Схема «исходники → проверенные заметки → результат» применима к текущему процессу NFAI. Исходники остаются вне Git, проверенные разборы идут в `results/`, ссылки на роли и задачи ведёт общий граф, а решения фиксируются в журнале. |

В корне репозитория точка входа для ролей — `AGENTS.md`. Claude Code поддерживает его прямое чтение с версии 2.1.277 при подходящих настройках проекта. Изолированный обработчик документов запускается в отдельной папке, поэтому для учебной задачи ему передают выбранный публичный текст. Для общего графа дополнительный vault не требуется.

Продукт и тестирование сверили путь `telegram-parser → telegram-tooling → tester`. [Упражнение для агентов](../review/knowledge-handoff.md) использует существующий граф и дорожную карту.
