# Восстановление задачи после сжатия контекста

28 октября · [Видео, 00:17–00:35](https://www.youtube.com/watch?v=6Pd4lyo83fU) · [Хуки Claude Code](https://code.claude.com/docs/en/hooks)

Название второго мода в доступной расшифровке не указано. Документация Claude Code подтверждает отдельное событие PreCompact. [Прежний разбор](06-claude-project-memory.md) покрывает долговременную память проекта. Новая практика — в длинной задаче до смены сессии сохранить короткую контрольную точку: ветка или SHA, проверенный результат, оставшийся шаг, команда проверки и путь к источнику. Для публикации использовать только разрешённые материалы.

Проверка для Профессора: открыть [прошлую контрольную точку](../review/2026-11-18-checkpoint.md), найти границу 2 октября и воспроизводимое упражнение, затем подтвердить путь к упражнению. Этот приём уже помог возобновить разбор. Автоматический хук в этом прогоне не устанавливался.
