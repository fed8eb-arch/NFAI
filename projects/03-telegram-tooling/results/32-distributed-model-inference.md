## Возможный проект для исследования

[Petals, BigScience](https://github.com/bigscience-workshop/petals) описывает распределённый инференс с участием добровольных узлов. Документация предупреждает, что публичный рой обрабатывает данные через сторонние узлы, и предлагает частный рой для чувствительных данных. MIT-лицензия репозитория не заменяет проверку лицензии каждой выбранной модели.

GitHub-поиск в NFAI по Petals и ID видео не дал совпадений. Проверка поисковым инструментом `health.petals.dev` завершилась недоступностью URL. Следовательно, текущее состояние узлов, задержка, квота, конфиденциальность конкретной конфигурации и интеграция с OmniRoute не подтверждены. Проект не установлен и не запускался, вычислительные ресурсы не предоставлялись. Использовать открытый демонстрационный материал для последующего теста, если доступ к сети и совместимой модели появится.
