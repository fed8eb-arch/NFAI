# Расчёт длительности сценария Reels

[Ранее выявленная проблема](30-instagram-skill-language-check.md): инструмент beats.py считал русские слова нулём. В проект добавлена адаптация из [instagram-agent-skill](https://github.com/Jakeschincariol/instagram-agent-skill), файл `skills/ig-reel/beats.py`, исходный Git blob `7f2db6a0af656075c571a77b405b06b2857ad021`. Автор Jake Schincariol, сохранена [лицензия MIT](../work/reel-timing/LICENSE).

Изменён подсчёт слов на Unicode. Для текста с не-ASCII символами признаки, зависящие от английской лексики, опущены, поле `concrete` равно `null`. Скорость речи и целевая продолжительность должны быть конечными положительными числами. Пустой сценарий и текст без слов отклоняются.

Из корня NFAI для сценария в UTF-8:

```sh
python3 projects/03-telegram-tooling/work/reel-timing/beats.py script.txt --wpm 165 --target 30 --json
```

На трёх русских предложениях тест получил 15 слов и 5,45 с при 165 словах в минуту. На трёх английских предложениях — 21 слово и 7,64 с. Смешанная строка из четырёх слов при 120 словах в минуту дала 2 с. Пустой ввод, сценарий только из знаков, нулевая скорость, нулевая цель и `nan` отклонены. Проверено выполнение на Python 3 без внешних зависимостей. Опубликованный код перечитан из main и сравнен с испытанной копией.

Длительность — арифметическая оценка, зависящая от выбранной скорости. Реальное время проверьте записью голоса. Английские эвристики не являются доказательством просмотров или результата рекламы. Русская оценка качества хуков и интеграция в автоматический запуск агентов не проверены.
