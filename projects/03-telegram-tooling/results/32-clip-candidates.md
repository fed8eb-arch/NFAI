# Поиск фрагмента по фразе

Для видеоредактора. [Ролик о коротких клипах](https://www.youtube.com/watch?v=5FMIw1QhL6E) предложил автоматический выбор моментов. Новый скрипт помогает найти **заданную редактором фразу** в SRT, в том числе между пословными титрами. Он возвращает совпадения и границы предлагаемых клипов в миллисекундах с контекстом с обеих сторон. Длительность считывается через ffprobe, интервалы ограничены границами медиа. Перед поиском применяется существующий валидатор субтитров.

```sh
python3 projects/03-telegram-tooling/work/find_clip_candidates.py captions.srt input.mp4 --phrase 'нужная фраза' --context-seconds 5
```

Код 0 — есть совпадения, 1 — нет совпадений, 2 — ошибка входных данных или media. Вывод — массив JSON. Проверено на синтетическом 10-секундном MP4 и трёх русских титрах. Поиск «привет мир» через два титра вернул совпадение 1000–3000 мс и клип 0–5000 мс. Совпадение в конце файла с пятью секундами контекста ограничено 4000–10000 мс. Несуществующая фраза вернула 1, параметр контекста nan — 2.

Это поиск буквальной фразы без учёта регистра. Качество распознавания речи и содержательную ценность найденного момента проверяет редактор по оригиналу. Алгоритм не определяет вирусность и не выбирает моменты без поисковой фразы.

Дополнительная сквозная проверка: найденный интервал 0–5 секунд вырезан из тестового видео через FFmpeg. Существующий `clip_captions.py` подготовил SRT для этого отрезка, `check_short_captions.py` вернул `OK: 2 cues, video duration 5.000s`. Оба имеющихся скрипта совпали с опубликованными версиями по Git blob. Исходное видео синтетическое, проверка не оценивает смысл и визуальное качество.
