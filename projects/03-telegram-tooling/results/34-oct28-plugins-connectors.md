# Плагины и коннекторы · 28 октября

[Пять плагинов](https://www.youtube.com/watch?v=h1wkqOygKTI), встроенный автоматический текст YouTube, 00:00–00:54. Название первого распознано неточно, вероятно маршрутизатор; 00:15 — Claude Mem, 00:23 — Headroom, 00:31 — Claude Code Setup, 00:45 — Task Observer. Числа провайдеров и обещание неограниченного бесплатного использования — заявления автора. Условия, исходники и пригодность отдельных плагинов ещё требуют проверки. В NFAI уже есть локальный маршрут OmniRoute, [описание](../../02-infrastructure/work/claude-local/README.md), а также [приём сокращения вывода](04-lowfat.md). Наличие маршрута не доказывает запуск остальных плагинов.

[Пять коннекторов](https://www.youtube.com/watch?v=KEhRgH1YpNo), встроенный автоматический текст YouTube: 00:00 — Perplexity, 00:07 — Firecrawl (в тексте распознано неточно), 00:15 — PostHog, 00:23 — Playwright, 00:38 — Composio. Возможности и доступы являются заявлениями автора. Перед подключением требуется найти официальную документацию и проверить бесплатный путь, полномочия и работу в целевой среде. Новых подключений по этому ролику не выполнялось.

[Сохранение работы](https://www.youtube.com/watch?v=6Pd4lyo83fU), расшифровка 00:17–00:35: автор описывает бриф перед сжатием сессии, но название дополнения не разборчиво. Это совпадает с [результатом 17](17-session-continuity.md). Проектный PreCompact проверялся на синтетическом вводе; интерактивный цикл /compact в том тесте не подтверждён.
