# Oracle Cloud Always Free

[Видео](https://www.youtube.com/watch?v=oJ3H_4UbsAo) · [ресурсы Always Free](https://docs.oracle.com/en-us/iaas/Content/FreeTier/freetier_topic-Always_Free_Resources.htm) · [условия регистрации](https://www.oracle.com/cloud/free/faq/)

| Таймкод | Проверка |
|---|---|
| 00:00–00:16 | Oracle описывает возможную комбинацию двух AMD Micro и одной ARM VM с 2 OCPU и 12 ГБ памяти. Применяются общий лимит дисков, доступность мощностей и ограничения домашнего региона. |
| 00:16–00:24 | Документация подтверждает две Always Free Autonomous Database по 20 ГБ и 10 ТБ исходящего трафика в месяц. |
| 00:24–00:36 | Доступность непрерывной работы не гарантируется. Oracle может изъять простаивающие виртуальные машины. |

Решение: оставить Oracle как вариант инфраструктуры. Регистрация требует платёжного метода для проверки личности, поэтому в текущем сценарии NFAI без карты облачные ресурсы не создавались. Локальное восстановление исходников проверено отдельно.
