# Проверка кандидата Instagram Agent Skill

Кандидат для [ролика](https://www.youtube.com/watch?v=l-D8PdsVdAw) — [Jakeschincariol/instagram-agent-skill](https://github.com/Jakeschincariol/instagram-agent-skill). README описывает 13 навыков и 26 шаблонов начала ролика. В видео называются 30 навыков и 26 формул. Сходство функций не подтверждает, что это тот же репозиторий.

Владельцем опубликована MIT License. При копировании необходимо сохранять текст лицензии и указание авторства. В этой проверке исходники не внесены в репозиторий.

## Практическая проверка

Из репозитория main получены `skills/ig-reel/hookscore.py` (Git blob c5299c59687070dc9b22561dcf3842908f204d96) и `beats.py` (Git blob 7f2db6a0af656075c571a77b405b06b2857ad021). Локальный запуск Python с двумя тестовыми формулировками на одной теме, проверка презентаций:

- `hookscore.py --hook "Three checks before you deliver a client deck"` вывел 8 слов, оценку 81.4.
- `hookscore.py --hook "Три проверки перед отправкой презентации клиенту"` вывел 0 слов, оценку 8.4.
- `beats.py` на коротком английском тексте определил 21 слово и оценку длительности 7.6 с при 165 словах в минуту.
- `beats.py` на русском тексте из трёх предложений указал 0 слов и 0.0 с. Показатели для кириллицы ошибочны.

Код `beats.py` получен с Git blob `7f2db6a0af656075c571a77b405b06b2857ad021`. Английские оценки являются эвристикой разработчика и не являются измерением охвата, результата рекламы или конверсии. Для русских сценариев эти версии требуют доработки и повторной проверки. Интеграция, обучение агентов и автоматический постинг здесь не выполнялись.
