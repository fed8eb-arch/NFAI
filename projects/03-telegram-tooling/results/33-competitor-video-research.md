# Ресерч тем видеоканала

[Источник](https://www.youtube.com/watch?v=pnBuuH-Vy4U), встроенный текст YouTube: на 00:08 автор предлагает vidIQ, на 00:12–00:24 — выбрать канал по теме и изучить видео, на 00:24–00:34 — адаптировать идеи для своей аудитории. Описание автора уточняет три шага. Расширение vidIQ и доступ к данным через Claude здесь не устанавливались и не проверялись.

Для исследователя рынка добавлен `../work/research_video_rank.py`. Заполните CSV из открытых страниц одного канала, обязательно с колонками `title,url,views,published,observed`; даты в ISO 8601. Каждая строка — видео, просмотры — целое неотрицательное число. Запустите из корня NFAI:

```sh
python3 projects/03-telegram-tooling/work/research_video_rank.py /path/to/videos.csv
```

Вывод JSON отсортирован по просмотрам. Для каждого кандидата сохранены адрес и обе даты. После сортировки исследователь вручную проверяет тему, описание, аудиторию и делает собственные идеи. Просмотры не показывают причины роста, удержание, конверсию или прибыль. Старые ролики и форматы могут иметь разный период накопления просмотров. Повторы URL в разных форматах нужно сверить перед вводом.

Проверено: две тестовые строки в обратном порядке дали сортировку 50 → 5; отрицательное число просмотров отклонено с кодом 2. Отдельно обработана одна открытая страница источника: 12 060 просмотров, дата публикации 28 октября, дата наблюдения 19 ноября 2026, что подтверждает обработку одной реальной строки. Это не сравнение конкурентов и не измерение охвата агентства.
