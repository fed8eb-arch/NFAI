# Бриф для демонстрации проверки презентации

Исполнитель: маркетинг · статус: внутренний черновик · 18 ноября 2026.

Материал подготовлен по [общему контексту](../../../.agents/product-marketing.md) и [доказательству проверки](24-presentation-acceptance.md). Основа метода — учитывать продукт, аудиторию и подтверждённые факты при подготовке контента, описанного в [marketing skills](https://github.com/coreyhaines31/marketingskills). Текст написан для NFAI, исходный пакет не установлен.

## Поручение

Подготовить краткое описание внутренней демонстрации для человека, который получает презентацию по брифу и хочет сверить число слайдов. Желаемое действие — передать тестовый PPTX и ожидаемое число слайдов исполнителю демонстрации. Публичные сообщения и работа с реальными клиентами регулируются действующими полномочиями агентства.

## Черновик

**Сверьте презентацию с числом слайдов из брифа**

В тестовом процессе NFAI файл PPTX можно проверить на нужное количество слайдов и наличие нативного текста хотя бы на одном слайде. Для демонстрации передайте исполнителю тестовый файл и число слайдов из брифа.

После автоматической проверки презентацию нужно открыть и проверить содержание, оформление, переносы и цвета. Проверка не подтверждает редактируемость всех элементов.
