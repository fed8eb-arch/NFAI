# Сверка документации и локальный видеоклип

## Документация библиотеки, 21 октября

[Ролик, 00:13–00:21](https://www.youtube.com/watch?v=Q2KwC8K-Zpc) · [Context7](https://github.com/upstash/context7)

Agent Skills и граф уже разобраны в [01](01-claude-code-addons.md). Новое правило для разработчика: перед использованием API определить установленную версию и найти первичную документацию для неё. Context7 умеет выбирать документы по ID библиотеки и запросу с версией, но проект рекомендует проверять сведения. В этом прогоне сравнили текущую версию Claude Code 2.1.327 с документацией шлюзов и проверили реальный HTTP 200. Context7 не подключался.

## Нарезка видео, 15 ноября

[Ролик, 00:06–00:28](https://www.youtube.com/watch?v=5FMIw1QhL6E) · [SupoClip](https://github.com/cspenn/supoclip)

К раскадровке из [14](14-storyboard-and-ai-search.md) добавилась проверка выходного медиа. В локальном тесте FFmpeg взял три секунды из шестисекундного синтетического видео. После обрезки и масштабирования ffprobe подтвердил 360×640, SAR 1:1 и длительность 3,000 с. Подходит как упражнение для контента и QA. Автоматический подбор фрагментов, трекинг лица и субтитры не проверялись. SupoClip не устанавливался.
