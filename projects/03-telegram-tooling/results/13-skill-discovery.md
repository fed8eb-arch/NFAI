# Загрузка скиллов по задаче

02.10.2026 · [Видео](https://www.youtube.com/watch?v=XB0ZfWpXejw) · [Anthropic о формате скиллов](https://www.anthropic.com/engineering/equipping-agents-for-the-real-world-with-agent-skills) · [Спецификация Agent Skills](https://agentskills.io/specification)

На 00:16–00:46 описан поиск по коротким описаниям и чтение полной инструкции только для выбранного навыка. Это соответствует progressive disclosure в Agent Skills. Конкретный MCP и размер его каталога в доступной расшифровке независимо не подтверждены.

**Применение NFAI.** Для проектного скилла указывать назначение и тип задач в `description`. Обязательный порядок хранить в `SKILL.md`, длинные примеры — в связанных файлах, которые нужны только для конкретного шага. До переноса внешнего навыка проверить точный источник, лицензию, зависимости и конфликт правил. Для первого контрольного примера открыли установленный в репозитории дизайн-скилл и проверили, что его описание позволяет выбрать его для UI-ревью. Новый сервер или каталог не подключались.
