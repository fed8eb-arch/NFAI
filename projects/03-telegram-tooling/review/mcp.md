# MCP для NFAI

- **NFAI Memory.** Проверены инициализация, список ролей, связи Джокера и ответ на неизвестный ID. Сервер читает только общий граф.
- **Playwright 0.0.85.** Проверены запуск установленного сервера по MCP и список инструментов. Запуск браузера в текущей среде заблокирован. Системный Chromium получил отказ при открытии сокета, а загрузку Chrome Headless Shell остановила сетевая политика. Для визуальной проверки доступен браузер рабочей среды.
- **Figma.** Подключение к файлу и проверка ждут подтверждённого доступа.

Оба проектных сервера видны в `claude mcp list`. Claude Code запросит одобрение при первом использовании. Конфигурация не содержит ключей.
