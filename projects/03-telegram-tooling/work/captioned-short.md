# Вертикальный клип с субтитрами

Для контент-редактора. [Результат 21](../results/21-versioned-docs-and-local-clip.md) уже проверил нарезку. Этот прогон добавляет встраивание готовых субтитров, сохранение звука и проверку времени их показа. Исходный ролик 5FMIw1QhL6E, 00:06–00:28. [Основной репозиторий SupoClip](https://github.com/FujiwaraChoki/supoclip) указывает Docker, AssemblyAI для транскрипции и провайдера модели. Автоматический поиск моментов и транскрипция SupoClip в этот тест не входили.

## Экспорт

В одном каталоге нужны исходник input.mp4 и проверенный редактором файл captions.srt в UTF-8. Таймкоды SRT отсчитываются от начала выходного клипа. Пример первого титра:

```srt
1
00:00:00,500 --> 00:00:02,000
Проверка субтитров
```

Нужен FFmpeg с libass и libx264. Команда берёт три секунды начиная с первой секунды исходника. Значения менять по монтажному листу. Используется центральное кадрирование, поэтому редактор проверяет положение объекта в кадре перед сдачей. При существующем clip.mp4 команда останавливается.

```sh
ffmpeg -nostdin -n -v error -ss 1 -i input.mp4 -t 3 -map 0:v:0 -map '0:a?' -vf 'scale=360:640:force_original_aspect_ratio=increase,crop=360:640,setsar=1,subtitles=captions.srt' -c:v libx264 -pix_fmt yuv420p -c:a aac -movflags +faststart clip.mp4
ffprobe -v error -show_entries stream=codec_name,width,height,sample_aspect_ratio:format=duration -of json clip.mp4
```

## Проверка от 18 ноября 2026

Для повторения используйте в чистом каталоге этот исходник, SRT выше и команду экспорта:

```sh
ffmpeg -n -v error -f lavfi -i color=c=blue:size=640x360:rate=25 -f lavfi -i sine=frequency=220 -t 4 -c:v libx264 -c:a aac input.mp4
```

ffprobe показал H.264, 360×640, SAR 1:1, звук AAC, длительность 3,000 с. На однотонном фоне подсчитаны светлые пиксели. На отметках 0,2 и 2,5 с их было 0, а в 1,0 с во время титра — 1626. При другой версии шрифта число может отличаться. Критерий — появление и исчезновение надписи внутри её временного окна. На клиентском видео проверьте читаемость, синхронизацию и кадрирование визуально.

## Субтитры из исходного длинного видео

Если SRT имеет таймкоды исходного видео, преобразуйте его под выбранный фрагмент. Скрипт обрезает пересекающие границы субтитры, сдвигает время к началу клипа, перенумеровывает записи и не перезаписывает существующий файл. Время задаётся относительно исходного видео в формате SRT. Выбор момента выполняет редактор.

```sh
python3 projects/03-telegram-tooling/work/clip_captions.py full.srt captions.srt --start 00:00:01,000 --end 00:00:03,000
python3 projects/03-telegram-tooling/work/check_short_captions.py captions.srt clip.mp4
```

Проверка на синтетическом двухсекундном ролике и трёх исходных титрах: два пересекающих фрагмент титра обрезаны до 00:00:00,000–00:00:00,500 и 00:00:01,000–00:00:02,000. Валидатор вернул `OK: 2 cues`. Существующий выходной файл и интервал без титров отклонены. На реальной записи проверьте синхронизацию и читаемость. Автоматический выбор фрагментов здесь не реализован.
