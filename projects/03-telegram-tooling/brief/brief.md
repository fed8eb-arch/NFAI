# Telegram research intake

Plan: Import one user-selected Telegram chat export, inventory two months of videos, and check each candidate before adoption.

- Owner: Telegram Parser for intake and timestamped extraction, Tester for verification, Orchestrator for prioritization, Joker for approved integrations.
- Scope: one user-selected chat. Keep exports, attachments, transcripts and private links outside the public repository.
- Budget: $0. No paid trials. Follow project rules for account creation, permissions and external changes.
- Acceptance: normalize and deduplicate YouTube videos, retain Telegram post dates, distinguish inaccessible items, and trace findings to video timestamps. For each proposed adoption, verify upstream documentation and prerequisites, run a representative test, and record what worked. Start with the visible history of the selected channel. Use the single-chat export path when available to cover dates and attachments outside the visible history.
- Report: Russian, with practical uses, evidence, installation status and blockers. Coverage remains partial until the requested date range can be checked.
